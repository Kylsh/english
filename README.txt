1. Create a new empty repository on github.com.
2. Upload ALL files of this folder (including the hidden .github folder) to it.
3. Open the Actions tab -> "Build APK" -> wait ~5 minutes.
4. Open the finished run -> Artifacts -> english3-apk -> download, unzip, get app-debug.apk.
5. Send app-debug.apk to the phone and install it (allow "install unknown apps").
